# Guía Visual de Ecualización & Mezcla en Behringer XR18
## Rock Clásico & Heavy Metal (Metallica / Iron Maiden)

Guía interactiva diseñada para una banda de 4 integrantes con:
- Consola digital **Behringer XR18 (X-Air)**.
- 2 Guitarras eléctricas directas con modelador **NAM (Neural Amp Modeler)**.
- Ambas guitarras alternan roles de **Voz Líder** y **Coros**.
- Bajo eléctrico + Subwoofers de **18"** + Tops **JBL**.
